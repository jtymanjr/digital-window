# Digital Window

A head-tracked 3D "window": the front camera follows your eyes and the scene is drawn with an off-axis projection, so the screen looks like a pane of glass with scenery behind it.

Open `index.html` over https (GitHub Pages) or as a local file in Chrome, then press **Start with camera**. Use **Calibrate** to set screen size, camera position and viewing distance.

Built with three.js and MediaPipe Face Landmarker, both loaded from CDNs.
